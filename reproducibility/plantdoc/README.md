# PlantDoc experiments

This folder contains the fixed 27-class PlantDoc splits, the executed five-model comparison notebooks, compact three-seed training results, and the final test-set evaluation.

The prepared Kaggle dataset is `sayemahmedshayeed/plantdoc-clean-grouped-v1`. It was constructed from the Kaggle PlantDoc dataset at `nirmalsankalana/plantdoc-dataset`. Image files are not included here.

The model checkpoints required to repeat test inference are listed in the checkpoint registry and `../../external_artifacts.csv`.

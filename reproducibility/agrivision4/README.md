# AgriVision4 experiments

This folder contains the AgriVision4 evidence reported in the paper: the fixed 21-class dataset splits, five-model comparison notebooks, test-set evaluation, eight three-seed architectural ablations, and the Grad-CAM, calibration, and error analysis.

The dataset metadata identifies the prepared Kaggle dataset as `sumitnath07/agrivision4-clean-grouped-v1`. Image files are not included here. The split CSV files specify the samples used by each experiment.

The model checkpoints required to repeat test inference are listed in the checkpoint registry and `../../external_artifacts.csv`.

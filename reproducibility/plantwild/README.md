# PlantWild experiments

This folder contains the fixed 105-class PlantWild splits, the five-model scratch comparison, final test-set evaluation, T4 model-only efficiency benchmark, and post-selection WaveDown confirmation.

The image files are not included. Use the fixed split CSV files in `data_protocol/manifests/` with the PlantWild v2 images used by the study.

Four model-comparison notebooks contain saved execution output. The MobileNetV3-Large notebook is a source-only runnable copy; the complete three-seed result bundle and frozen-checkpoint registry are included. Checkpoints are listed in `../../external_artifacts.csv`.
